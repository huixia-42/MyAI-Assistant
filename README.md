# MyAI-Assistant (version 1)

这是一个基于大语言模型（DeepSeek）从零手搓的桌面智能体（Agent）项目。它不仅是聊天机器人，更是集成了长短期记忆、情绪感知语音、联网检索与系统级工具调用的完整应用。

## 🌟 核心功能
- **持久化记忆**：能够自动提取对话核心信息并保存到本地，下次启动时静默加载，建立跨越时间的羁绊。
- **情绪感知语音**：通过正则解析大模型输出的情感标签，动态调用本地 TTS 引擎（VOICEVOX），实现普通、惊讶、害怕、疲惫等不同情绪的语音表达。
- **自主联网搜索**：当遇到未知实时信息时，AI 会主动触发指令调用搜索引擎，并将结果二次总结后回复。
- **系统级工具调用（Agent）**：能够识别指令，直接调用 Windows 系统接口打开计算器、记事本等本地软件。
- **模块化架构**：代码解耦为大脑（API/记忆）、嘴巴（TTS 语音）、工具（Agent）与主控台（main），高内聚低耦合。

## 🛠️ 技术栈
- **语言**：Python 3.11
- **大模型**：DeepSeek API
- **语音合成**：VOICEVOX Engine (本地部署)
- **音频控制**：Pygame
- **网页检索**：baidusearch
